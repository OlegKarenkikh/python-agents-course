## 🧠 Часть 1: Что такое LLM?

**LLM** (Крупная Языковая Модель) — это программа, которая научилась понимать и генерировать текст на огромном количестве данных.

```
Как обучалась модель GPT:

Много текста    Анализ        Модель
(триллионы      закономерностей  знает:
слов)
📚 📚 📚  →  🔍🔍🔍  →  «после ‘солнце’
                        часто идёт ‘светит’»
                        «после ‘заявка’
                        часто идёт ‘название’»
```

---

## 🔢 Часть 2: Токены

Токен — это **кусочек текста**. Модель работает с токенами, а не со словами. Стоимость API тоже считается в токенах.

```
Пример разбиения на токены:

"Заявка на сервер"
   ↓
["Заявка"] ["на"] ["сер"] ["вер"]
 = 4 токена

Примерная стоимость:
  GPT-4o:    $5 за 1 000 000 токенов
  GPT-3.5:   $0.50 за 1 000 000 токенов
  GitHub:    БЕСПЛАТНО (c ограничениями)!
```

## 🔑 Часть 3: API — как общаться с моделью

**API** (Интерфейс Программирования) — это способ, которым одна программа говорит с другой.

```
Ваша программа              Сервер OpenAI

💻  —— запрос: "В чём                   ☃️
         смысл жизни?" →→→→→→
                                     ‼️
💻  ←←←←← ответ: "42" ————————─
```

Мы отправляем **HTTP-запрос** (как сообщение по интернету) с текстом и получаем ответ.

## 🚧 Часть 4: GitHub Models — бесплатный LLM

В реальном проекте `dzo-tz-agents` используется **GitHub Models** — бесплатный доступ к GPT-4o через `GITHUB_TOKEN`.

```python
import os
from openai import OpenAI

# Получаем токен автоматически (GitHub Codespaces)
github_token = os.environ.get("GITHUB_TOKEN", "")

# Создаём клиента
client = OpenAI(
    api_key=github_token,
    base_url="https://models.inference.ai.azure.com",
)

# Отправляем запрос
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {
            "role": "system",
            "content": "Ты — помощник, проверяющий заявки."
        },
        {
            "role": "user",
            "content": "Проверь: Название: закупка серверов, количество: 5 шт"
        },
    ],
)

print(response.choices[0].message.content)
```

## 💬 Часть 5: Промпты — инструкция для модели

**Промпт** — это инструкция, которая сообщает модели, как себя вести.

```
Структура промпта:

┌───────────────────────────────────────────┐
│  system: "Ты — эксперт по заявкам.          │
│           Вежливый деловой тон."          │
│           (настраиваем поведение)          │
├───────────────────────────────────────────┤
│  user:   "Проверь заявку: ..."               │
│           (наш запрос)                           │
├───────────────────────────────────────────┤
│  assistant: "Заявка полная. Регистрирую." │
│             (ответ модели)                     │
└───────────────────────────────────────────┘

Типы промптов:
  system   → правила игры (не виден пользователю)
  user     → запрос пользователя
  assistant→ ответ модели
```

> Диалог из реального проекта см. `agent1_dzo_inspector/agent.py` — `SYSTEM_PROMPT`
