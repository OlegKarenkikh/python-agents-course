## 🤔 Зачем вообще программировать?

Представьте: у вас есть 1000 писем, и в каждом нужно проверить — правильно ли заполнена заявка. Вручную это займёт недели. Программа сделает это за минуты.

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   Человек:  📧 → читает → думает → пишет ответ     │
│             (5 минут на письмо × 1000 = ~83 часа)  │
│                                                     │
│   Программа: 📧 → анализирует → отвечает            │
│             (0.1 секунды × 1000 = ~2 минуты)        │
│                                                     │
└─────────────────────────────────────────────────────┘
```

Программирование — это способ **объяснить компьютеру, что делать**, чтобы он делал это вместо вас.

## 🐍 Почему Python?

Существуют десятки языков программирования. Python выбирают новички и профессионалы, потому что:

```
┌─────────────────────────────────────────────────────────────┐
│  Сравнение языков для новичка                               │
│                                                             │
│  Java:    public static void main(String[] args) { ... }    │
│           (много лишних слов)                               │
│                                                             │
│  C++:     int main() { std::cout << "Привет"; return 0; }   │
│           (непонятные символы)                              │
│                                                             │
│  Python:  print("Привет!")                                  │
│           (просто и понятно!)  ✅                            │
└─────────────────────────────────────────────────────────────┘
```

Kроме того, Python — **язык №1** для:
- 🤖 Искусственного интеллекта
- 📊 Анализа данных
- 🌐 Веб-разработки
- 🔧 Автоматизации

## 📦 Установка

### Шаг 1: Установите Python

1. Откройте браузер и перейдите на [python.org](https://python.org)
2. Нажмите большую жёлтую кнопку **Download Python 3.11+**
3. Запустите скачанный файл
4. ⚠️ **ВАЖНО:** Поставьте галочку **«Add Python to PATH»** внизу окна установщика!
5. Нажмите «Install Now»

### Шаг 2: Проверьте установку

Откройте командную строку (Terminal / cmd) и введите:
```bash
python --version
```
Должно появиться: `Python 3.11.x` (или новее)

### Шаг 3: Установите VS Code

1. Перейдите на [code.visualstudio.com](https://code.visualstudio.com)
2. Скачайте и установите VS Code
3. Откройте VS Code → Extensions (Ctrl+Shift+X) → найдите **«Python»** → Install

```
┌─────────────────────────────────────────┐
│  Что у вас должно быть после установки  │
│                                         │
│  ✅ Python 3.11+                        │
│  ✅ VS Code                             │
│  ✅ Расширение Python для VS Code       │
└─────────────────────────────────────────┘
```

## 🎉 Первая программа

Создайте файл `hello.py` и введите:

```python
# Моя первая программа!
print("Привет, мир!")
print("Я учусь программировать.")
```

Запустите в терминале:
```bash
python hello.py
```

Результат:
```
Привет, мир!
Я учусь программировать.
Скоро я создам своего агента!
```

**Поздравляем!** Вы только что запустили первую программу. 🎊

## 🤖 Что такое агент (первое знакомство)

Агент — это программа, которая **сама принимает решения** и **использует инструменты** для выполнения задачи.

```
┌─────────────────────────────────────────────────────────┐
│  Обычная программа vs Агент                             │
│                                                         │
│  Обычная программа:                                     │
│  Задача → [фиксированные шаги] → Результат              │
│  (как рецепт: всегда одни и те же действия)             │
│                                                         │
│  Агент:                                                 │
│  Задача → [думает] → [выбирает действие] → [проверяет]  │
│           ↑_____________обратная связь__________________│
│  (как повар: адаптируется под ситуацию)                 │
└─────────────────────────────────────────────────────────┘
```

Пример из реальной жизни:
- **Обычная программа:** «Если письмо содержит слово 'заявка' — отправь ответ №3»
- **Агент:** «Прочитай письмо, пойми что нужно, проверь документы, реши что ответить»

К концу этого курса вы создадите настоящего агента!
