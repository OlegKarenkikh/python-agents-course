## 🤔 Зачем вообще программировать?

Представьте: у вас есть 1000 писем, и в каждом нужно проверить — правильно ли заполнена заявка. Вручную это займёт недели. Программа сделает это за минуты.

![Программа vs Агент — принципиальное отличие](https://user-gen-media-assets.s3.amazonaws.com/gemini_images/64430471-7079-4ab3-8a52-1f6fea484fc6.png)

```
┌─────────────────────────────────────────────────────┐
│   Человек:  📧 → читает → думает → пишет ответ     │
│             (5 минут на письмо × 1000 = ~83 часа)   │
│                                                     │
│   Программа: 📧 → анализирует → отвечает            │
│             (0.1 секунды × 1000 = ~2 минуты)        │
└─────────────────────────────────────────────────────┘
```

Программирование — это способ **объяснить компьютеру, что делать**, чтобы он делал это вместо вас.

```

## 🐍 Почему Python?

```
┌─────────────────────────────────────────────────────────────┐
│  Сравнение языков для новичка                               │
│  Java:    public static void main(String[] args) { ... }    │

## 📦 Установка

### Шаг 1: Python
1. [python.org](https://python.org) → Download Python 3.11+
2. ⚠️ **ВАЖНО:** галочка **«Add Python to PATH»**!
3. «Install Now»

```bash
python --version  # должно показать: Python 3.11.x
```

### Шаг 2: VS Code
1. [code.visualstudio.com](https://code.visualstudio.com) → скачать
2. Extensions (Ctrl+Shift+X) → «Python» → Install

## 🤖 Что такое агент — первое знакомство

Агент — программа, которая **сама принимает решения** и **использует инструменты**.

```
┌─────────────────────────────────────────────────────────┐
│  Обычная программа:                                     │
│  Задача → [фиксированные шаги] → Результат              │
│  (как рецепт: всегда одни и те же действия)             │
│                                                         │
│  Агент:                                                 │
│  Задача → [думает] → [выбирает действие] → [проверяет]  │
│           ↑_____________обратная связь__________________│
│  (как повар: адаптируется под ситуацию)                 │
└─────────────────────────────────────────────────────────┘
```
