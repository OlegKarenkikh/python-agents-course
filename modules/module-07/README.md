## 👥 Система агентов

В `dzo-tz-agents` работают **три агента** параллельно:

```
Три агента в одном сервисе:

   FastAPI
   │
   ├── /process/dzo    → [Агент ДЗО]
   ├── /process/tz     → [Агент ТЗ]
   ├── /process/tender → [Агент Тендер]
   └── /process/auto   → [Авто-определение типа]

Каждый агент — отдельный ReAct-граф.
Один запрос — один агент. Параллельно.
```

## 📊 Мониторинг

В `dzo-tz-agents` есть Prometheus + Grafana. Каждый вызов API записывается:

```python
# в api/app.py есть такой код:
from prometheus_client import Counter, Histogram

requests_total = Counter(
    "agent_requests_total",
    "Тотал запросов",
    ["agent", "status"]
)

# При каждом запросе:
requests_total.labels(agent="dzo", status="success").inc()
```

```
В Grafana вы видите:

 ┌────────────────────────────────────────┐
 │ Агент ДЗО: 247 запросов/час    │
 │ Агент ТЗ:  163 запроса/час     │
 │ Ошибки:   1.2%                    │
 │ Ср. время: 2.3 секунды         │
 └────────────────────────────────────────┘
```
