## 📦 Часть 1: Переменные и данные

Переменная — это **ящик** в памяти, в который мы кладём значение.

```python
# Примеры переменных
имя = "Алексей"          # строка (текст)
возраст = 25                   # целое число
уровень_опыта = 1.5            # дробное число
учеба = True                  # да/нет

print(имя)          # Алексей
print(возраст)        # 25
print(type(возраст))   # <class 'int'>
```

```
Типы данных в Python
───────────────────────────────────────
Тип       Пример           Когда использовать
───────────────────────────────────────
str       "Привет"        Текст, имена, фразы
int       42              Целые числа
float     3.14            Дробные числа
bool      True/False      Да/Нет
list      [1, 2, 3]       Список вещей
dict      {"a": 1}        Словарь (ключ-значение)
───────────────────────────────────────
```

## 📊 Часть 2: Списки и Словари

```python
# Список: порядок важен!
чек_лист = [
    "Название закупки",
    "Указать количество",
    "Дату поставки",
]

print(чек_лист[0])  # Первый элемент: Название закупки
print(len(чек_лист)) # Сколько элементов: 3

# Словарь: как настоящий словарь, только в коде
заявка = {
    "название": "Покупка серверов",
    "количество": 5,
    "дата": "2024-01-15",
    "бюджет": 500000,
}

print(заявка["название"])  # Покупка серверов
print(заявка["бюджет"])    # 500000
```

```
Сравнение: Список vs Словарь
┌─────────────────────────────────────────────────┐
│ Список ["a", "b", "c"]         │
│ • Номер: 0, 1, 2 (порядок важен)  │
│ • Используется для очередей      │
├─────────────────────────────────────────────────┤
│ Словарь {"key": "value"}       │
│ • Ключ: любое слово (порядок не важен) │
│ • Используется для атрибутов      │
└─────────────────────────────────────────────────┘
```

## 🔀 Часть 3: Условия и циклы

```python
# Условие: делаем разные действия в зависимости от ситуации
полнота = заявка["количество"]

if полнота == 5:
    print("Заявка полная! Отвечаем.")
elif полнота > 0:
    print("Заявка частичная, нужно дополнить.")
else:
    print("Заявка пустая!")

# Цикл: проходим по каждому пункту чек-листа
for пункт in чек_лист:
    print(f"  ✓ {'указан' if пункт in заявка.values() else 'проверяем'}: {'пункт'}")
```

```
Логика условия:

     if (условие)
          ↓
       True? ───────► Выполнить Блок A
          ┃
       False?──────► Выполнить Блок B
```

## 🔧 Часть 4: Функции

Функция — это **именованный блок кода**, который можно вызывать снова и снова.

```python
# В реальном проекте dzo-tz-agents есть такие функции:

def проверить_заявку(text: str) -> dict:
    """Проверяет заявку на полноту.
    
    Args:
        text: Текст заявки
    Returns:
        Словарь с результатами
    """
    результат = {
        "полная": False,
        "ошибки": [],
    }
    
    if "название" not in text.lower():
        результат["ошибки"].append("Отсутствует название")
    
    if len(text) < 50:
        результат["ошибки"].append("Слишком коротко")
    
    if not результат["ошибки"]:
        результат["полная"] = True
    
    return результат

# Использование:
текст = "Заявка: название - покупка оборудования, количество 10 шт."
рез = проверить_заявку(текст)
print(рез)  # {'полная': True, 'ошибки': []}
```

## 🏗️ Часть 5: Классы

Класс — это **чертёж**, по которому создаются объекты.

```python
# В реальном проекте есть класс AgentRunner:

class Инспектор:
    """Проверяет заявки на полноту."""
    
    def __init__(self, название: str):
        self.название = название
        self.проверено = 0  # счётчик проверок
    
    def проверить(self, текст: str) -> str:
        self.проверено += 1
        рез = проверить_заявку(текст)
        статус = "✅ полная" if рез["полная"] else f"❌ ошибки: {', '.join(рез['ошибки'])}"
        return f"[{self.название}] Заявка #{self.проверено}: {'статус'}"

# Использование:
инсп = Инспектор("Инспектор-ДЗО")
print(инсп.проверить(текст))
print(инсп.проверено)  # 1
```

```
Класс — это как папка с полями и методами:

┌────────────────────────────────┐
│  class Инспектор           │
│  ┌──────────────────────┐ │
│  │ Данные (атрибуты): │ │
│  │   название         │ │
│  │   проверено         │ │
│  ├──────────────────────┤ │
│  │ Методы (функции): │ │
│  │   проверить()      │ │
│  └──────────────────────┘ │
└────────────────────────────────┘
  ↓↓↓ Создаём объекты
┌───────────┐ ┌───────────┐
│Инсп-ДЗО │ │Инсп-ТЗ  │
└───────────┘ └───────────┘
```
