## 🎯 О курсе

Этот курс создан на основе реального проекта [dzo-tz-agents](https://github.com/OlegKarenkikh/dzo-tz-agents) — системы LLM-агентов для автоматической проверки заявок. Вы пройдёте путь от «что такое программирование» до «я написал своего агента с ИИ».

**Для кого этот курс:**
- 🆕 Полные новички без опыта в IT
- 🐍 Те, кто знает Python на базовом уровне
- 🤔 Те, кто слышал про ИИ-агентов, но не понимает, как это работает

**Что вы получите:**
- Понимание Python с нуля
- Понимание того, как работают LLM и ИИ-модели
- Умение создавать агентов на LangChain/LangGraph
- Готовый рабочий проект в портфолио

## ⚡ Быстрый старт

```bash
# 1. Клонируем курс
git clone https://github.com/OlegKarenkikh/python-agents-course.git
cd python-agents-course

# 2. Создаём виртуальное окружение
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. Устанавливаем зависимости
pip install -r requirements.txt

# 4. Начинаем с модуля 0!
cd modules/module-00
```

## 💡 Как учиться

1. **Читайте теорию** в `README.md` каждого модуля — там есть схемы и объяснения
2. **Запускайте примеры** — каждый пример можно и нужно изменять
3. **Делайте практику** — задания в папке `practice/`
4. **Не смотрите в решения** раньше времени — в папке `solutions/`
5. **Задавайте вопросы** через Issues репозитория
